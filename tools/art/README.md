# The Enquire picture

The thinkpeople.io emblem (Vitruvian figure, the canonical X traced from the master TPN artwork,
rings, glow and the four coloured points) with the human and AI faces from the Enquire logo
looking in towards it.

- `trace_faces.py` turns the two face cut-outs into vector shapes (`faces.json`).
- `compose.py` builds `enquire-art.html` from the thinkpeople.io site source (index.html, vitruvian.webp).
- `shot.py out.png 2` renders it at 2x (3120 x 1760).

The published sizes live in `public/assets/enquire-art-*.webp` and `enquire-og.jpg` (link preview, 1200 x 630).
